“It’s jam time” 🍻😁

Mais avant, voyons rapidement ce qu’il nous reste à aborder pour mieux appréhender la jam :
* Un peu d’UI en 2D pour créer des menus et des interfaces
* Un aperçu de Mixamo, au cas où vous auriez besoin d’un personnage
* Un survol des nombreux nodes disponibles dans Godot, avec un focus sur les plus utiles

Et on y sera vite.

On n’aura pas tout vu 😉, mais c’est justement le principe d’une jam :   
faire un jeu avec ce que vous avez, pas avec ce que vous aimeriez avoir.   

Composez avec vos compétences et celles que vos partenaires apportent.   
   
Que le code soit avec vous 👍🐙
