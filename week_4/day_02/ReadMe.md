# Matin : Mixamo

Rien à faire, la capacité de Godot à importer des assets 3D en GLB reste impressionnante.
Essayez de télécharger des modèles depuis SketchUp et Mixamo.

Créons une petite application de slow motion pour des animations Mixamo.

Interface :

* Deux boutons pour tourner
* Deux boutons pour accélérer et ralentir la vitesse d’animation
* Un bouton pour passer à l’animation suivante
