# Setup Godot XR Toolkit

Il existe plusieurs moyens d’installer Godot XR.

Depuis l’AssetLib officiel de Godot dans l’engine.
Mais dans ce cas, vous aurez la dernière version que le développeur a jugée stable et qu’il a pris le temps de publier sur le store, puis que l’équipe a accepté.
Ce n’est jamais la version la plus actuelle.

L’autre méthode consiste à télécharger le zip du projet via le lien de la release :
[https://github.com/GodotVR/godot-xr-tools/releases](https://github.com/GodotVR/godot-xr-tools/releases)

Puis de dézipper le dossier `addons/godot-xr-tools` dans votre projet.

Attention : la release est en soi un projet Godot.
C’est lié à la façon dont on publie sur les stores.
Nous verrons cela plus tard dans le cours.

Sur Quest, pour tester, il vous faudra Fossify pour dézipper et déplacer le projet.

> Rappel : si je travaille sur Quest via Android et Termux, c’est pour plusieurs raisons.
> Mais la principale est que je n’ai pas de tour assez puissante pour la VR. 😉😋
> À prendre en considération si vous voulez faire de la VR hors formation à 330$.
