
## Fin de journée : Débogueur SSD1306

Nous avons appris à utiliser le SSD1306, car cela nous permettra de déboguer en XR.

Créez un code qui permet d’afficher:
- **les inputs des manettes du Quest**
- Optionel:
  - les inputs du claviers en format _input
  - les inputs du gamepad en formation depuis _input
  - la position et delta de la souris
- Challenge:
  - Utiliser les characters unicode pour detecter
    - un [barcode scan](https://www.amazon.com.be/s?k=scan+code)
    - un [badge nfc](https://www.amazon.com.be/s?k=badge+nfc)
    - cela permet de charger des scenes via un unique id.

Vous pouvez aussis par faciliter, ne pas uilisez le SSD1306 mais un simple Label3D
(Nico peu utiliser le CanvasLayer avec les UI de Godot si il veut 😉)

Le but ici est de vous laissez le temps de vous familiarisez avec l'Input de votre choix.
