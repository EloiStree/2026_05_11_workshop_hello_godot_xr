# KS4036
Info: [Quick](https://github.com/EloiStree/2026_03_23_doc_micro_bit_sensor/issues/220) more 
`~Sujet~` Pas certain de vouloir explorer cela ensemble

Composition: [Info](https://github.com/EloiStree/2026_03_23_doc_micro_bit_sensor/issues/220)
- Un Led Gauche et un Led Droite RGB
- Deux roues
- Movement en `differential drive`
  - Un vitesse propre au KS4036 
- Un detecteur de distance frontal
- Deux detecteurs de ligne en dessous
- un port pour le micro bit
  - Un micro bit avec le code
- ~Challenge: Deux capteurs lumineurs~
- Un recepteur infrarouge
  - Une telecommande infrarouge
- Autre: ~Batterie~, ~Des pins~,

- Le MicroBit sur le slote lui a:
  - ~Un Microphone~
  - ~Un capteur de temperatuer~
  - Un Compas
  - Un Gyroscope
  - Un speaker
  - ~Challenge: Du Bluetooht UART BLE~
