

# Fin de journée : Un capteur

Créons un git de groupe et donnons une vue à notre voiture.
Le but est de commencer le travail de demain : créer un asset pour le store Godot (library et bêta).

Chacun prend un capteur ou un moteur qu’il pense facile à coder.
Puis, sur une branche Git personnelle, créez un outil.

Une fois la fonctionnalité ajoutée, poussez votre code sur la branche de développement.

Le but est de terminer un capteur par personne d’ici demain midi.
