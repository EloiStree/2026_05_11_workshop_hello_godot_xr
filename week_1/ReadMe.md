**Objectif de la semaine :**   
Se familiariser avec Godot, Godot XR et GDScript.    

Le tutoriel 2D de Brackeys est particulièrement bien structuré, nous l’utiliserons donc pour les deux premiers jours.    

Cependant, difficile de parler de XR sans y toucher dès le départ 😉    
Avant de commencer, je vous propose donc de réaliser un petit “hello world” : simplement afficher un cube dans le casque.    

L’une des premières étapes sera la prise en main des manettes, puis le travail sur le toucher la semaine prochaine.    
Nous allons donc commencer par comprendre comment gérer les inputs dans Godot.    

Et comme rien ne se fait sans un minimum de code, nous aborderons le GDScript plus en profondeur vendredi, avec un exercice pratique sur le SSD1306.     

Voilà pour le programme.   

Hâte de voir vos premiers chevaliers sauter de bloc en bloc.   
C’est parti.
